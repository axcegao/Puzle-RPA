# BI чат-бот с интерактивной визуализацией данных

Решение кейса Puzzle RPA конкурса SK Kids Challenge 2026. Пользователь пишет
запрос на естественном языке, бот собирает единую таблицу из данных продаж,
планов и скидок, строит интерактивный дашборд прямо в чате, позволяет добавлять
вычисления колонками, фильтровать и переключать разрезы, сохранять дашборды
и экспортировать результат.

## Возможности и соответствие кейсу

| Требование кейса | Реализация |
| --- | --- |
| Запрос на естественном языке | rule-based NLU: намерения, разрезы, периоды, фильтры, имена дашбордов |
| Единая таблица для визуализации | витрина месяц x точка x продукт: факт, план, измерения |
| Интерактивные графики в чате | 4 графика Plotly: зум, hover, переключение легенды |
| Вычисления колонками | отклонение в рублях и процентах, выполнение плана, динамика к прошлому периоду и год к году, доля, накопительный итог, ранг, среднее, медиана, минимум, максимум, произвольная формула |
| Перестройка графиков с вычислениями | переключатель метрики, автоподстановка последнего вычисления |
| Фильтры с поиском и переключатели | мультивыборы с поиском значения, разрез, гранулярность периода, метрика |
| Итоговые цифры сверху | KPI-карточки с цветовой индикацией выполнения и отклонения |
| Уточняющие вопросы | бот спрашивает разрез, если он не назван в запросе |
| Текстовое резюме | период, лидер по объему, минимальное выполнение плана, активные фильтры |
| Сохранение и возврат | список дашбордов, открытие по имени, переименование, удаление |
| Экспорт | CSV для русского Excel, XLSX с ширинами столбцов, HTML офлайн |
| Безопасность формул | разбор через AST без eval, только имена колонок и арифметика |

## Стек

Python 3.13, pandas, plotly, FastAPI, uvicorn, openpyxl. Фронтенд - один
index.html на ванильном JavaScript. plotly.js отдается сервером из
установленного пакета, поэтому интерфейс и HTML-экспорт работают без интернета.

## Запуск

```powershell
git clone https://github.com/axcegao/Puzle-RPA.git
cd Puzle-RPA
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r backend\requirements.txt
cd backend
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

Открыть http://127.0.0.1:8000 в браузере. Если активация venv запрещена
политикой выполнения, используйте `.\.venv\Scripts\python.exe` вместо `python`
или выполните `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.

## Демо-сценарий

1. "Собери дашборд по продажам: план-факт по регионам за последний год" - KPI, четыре графика, резюме, таблица.
2. "покажи таблицу" - единая таблица с вычислениями.
3. "добавь колонку с процентом выполнения плана" - новая колонка и график по этой метрике.
4. "формула: (fact_amount - plan_amount) / plan_amount * 100 добавь колонку" - произвольная формула.
5. "перестрой график - отсортируй по проценту выполнения" - сортировка категорий.
6. Переключатель "Разрез:" на "Торговая точка" - горизонтальные графики, структура топ-8.
7. Переключатель "Период:" на "Кварталы" - пересчет зерна агрегации.
8. Фильтр "Регион", поиск "Центральный" - перерисовка дашборда на месте.
9. "покажи скидки по клиенту за последние 3 года" - вторая витрина со своими KPI.
10. "сохрани дашборд под названием «Продажи Q3»", "покажи мои дашборды", "открой дашборд «Продажи Q3»".
11. "скачай таблицу excel" и "скачай дашборд в html" - экспорт, HTML работает офлайн.

## Архитектура

- backend/db.py - загрузка CSV, обработка пропусков \N, сборка витрин продаж и скидок.
- backend/calculations.py - агрегации до зерна период x разрез, пресеты вычислений, безопасные формулы.
- backend/nlu.py - разбор сообщения в структуру Intent: намерение, разрез, гранулярность, период, фильтры, сортировка, имя дашборда, формат экспорта.
- backend/bot.py - сессии диалога, обработчики намерений, KPI, графики, резюме, хранение дашбордов, экспорт.
- backend/app.py - FastAPI: /api/chat, /api/rebuild, /files/{name}, /plotly.js, /.
- frontend/index.html - чат, дашборды, фильтры с поиском, переключатели, таблицы, ссылки экспорта.
- backend/test_flow.py - смоук-тест сквозного сценария.

Поток данных: запрос - NLU - выбор витрины - фильтры и период - агрегация -
вычисления колонками - KPI, графики, резюме, таблица - ответ в чат.
Вычисления выполняются на стороне бота после выгрузки данных, поэтому формулы
и разрезы меняются без повторных обращений к источнику.

## Данные

Восемь CSV в каталоге "Sk students data/data": clients, contracts, outlets,
products, regions, discounts, sales, sales_plan. План месячный и без привязки
к клиенту, поэтому план-факт считается на зерне месяц x точка x продукт.
Относительные периоды ("последний год", "последние 3 года") ограничены
последней датой факта, чтобы KPI не разбавлялся будущими плановыми месяцами.
Явные периоды ("за 2026 год") остаются как заданы.

## Экспорт

- CSV: разделитель точка с запятой, десятичная запятая, кодировка UTF-8 с BOM, русские заголовки.
- XLSX: русские заголовки, ширины столбцов по содержимому, числа без решеток в Excel.
- HTML: KPI-карточки, резюме и четыре графика, plotly.js встроен в файл, работает офлайн.

Файлы экспорта и сохраненные дашборды лежат в backend/storage и не попадают
в репозиторий.

## Проверка

```powershell
cd backend
python test_flow.py
```

Сценарий проверяет сборку дашборда, таблицу, вычисления, формулу, сортировку,
смену разреза и гранулярности, фильтры, витрину скидок, уточняющий вопрос,
сохранение, список, открытие, экспорт и интерактивную перестройку.
